# MySQL 8.0.22 Fuzz Grammar Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** Replace the canonical SELECT grammar with an MySQL 8.0.22-only grammar, stop fuzz from requesting unavailable schema families, and bound repeated compatibility-error loops without changing valid concurrency-error semantics.

**Architecture:** Narrow the canonical grammar asset at source and make every production generator load that single asset. Centralize fuzz query-generator construction so prewarm/inline/process paths share family exclusions, then classify connector errno explicitly and apply a small per-reader exponential backoff whose state is exposed through existing telemetry.

**Tech Stack:** Python 3.11, pytest, Pydantic configuration models, multiprocessing query generation, MySQL Connector/Python, Ruff, mypy, GitHub Actions.

- [ ] **Step 3: Preserve errno in execution results**

- [ ] **Step 4: Implement the pure backoff policy**

Create a small stateful unit:

```python
COMPATIBILITY_ERROR_ERRNOS = frozenset({1064, 1234, 1235, 1253})


@dataclass(slots=True)
class CompatibilityErrorBackoff:
    initial_seconds: float
    maximum_seconds: float
    streak: int = 0

    def observe(self, result: FuzzExecutionResult) -> float:
        if result.timed_out or result.errno not in COMPATIBILITY_ERROR_ERRNOS:
            self.streak = 0
            return 0.0
        self.streak += 1
        exponent = min(self.streak - 1, 30)
        return min(self.maximum_seconds, self.initial_seconds * (2**exponent))
```

Validate constructor bounds without duplicating Pydantic behavior and keep zero values
usable to disable the guard.

Instantiate one `CompatibilityErrorBackoff` per reader loop. Observe every execution result

```python
backoff_seconds = compatibility_backoff.observe(result)
if backoff_seconds > 0:
    self._telemetry.set_stage(worker_key, "compatibility_error_backoff")
    wait_started_ns = time.monotonic_ns()
    stopped = stop_event.wait(backoff_seconds)
    self._telemetry.observe(
        "compatibility_error_backoff_ns",
        max(0, time.monotonic_ns() - wait_started_ns),
    )
    if stopped:
        break
```

Keep the current MySQL session open and do not alter reconnect behavior.
